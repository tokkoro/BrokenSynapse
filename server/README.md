# Frozen Synapse LAN server

A replacement for the game's offline "Grand Server", so Frozen Synapse can be played on a LAN.

**Current stage:** accepts any username and password, fills the lobby, and creates matches from the Create Game
dialog (quick match against a named opponent) and plays them turn by turn. All traffic is logged both ways.

- `fsserver.py` handles connections and messages.
- `lobby.py` builds the lobby's text files.
- `games.py` stores matches in `server/data/` and reads and writes `.enc` headers.

The server never runs game logic itself; it asks a client to, by sending a script (`Eval`):

- New matches are generated by the challenger's client, with the game's own map generator, as the original server
  did with its `generateMFC` command.
- When both players have submitted a turn, the second player's client merges them with the engine's
  `collateTurnFiles` (or the game mode's `processBiddingTurn` for a bidding turn), like hotseat mode does. A merge
  left unfinished, for example by a disconnect, is retried when either player next logs in.

## Running

Requires Python 3.8 or later, with no dependencies.

```
python3 server/fsserver.py
```

Options: `--host` and `--port` (default `0.0.0.0:28021`), `--log-dir` (default `server/logs`) and `--upload-dir`
(default `server/uploads`). Each run writes a new log file.

## Connecting the game

1. On the login screen, click **ADVANCED**.
2. Enter the server's address (`127.0.0.1` on the same machine) and port `28021`.
3. Use the test button to check the connection, then confirm the server.
4. Log in with any username and password, or create an account. Both are accepted.

The game remembers the address but not the choice to use it, so step 3 is needed on every launch.
